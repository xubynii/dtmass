# Class deck slide — Downtown Massing Tool

**Tool name:** Downtown Massing Tool

**One sentence:** A browser tool that turns a program brief for a downtown Vancouver lot into an editable tower massing and checks it live against the Downtown ODP, the Vancouver Building By-law and the Parking By-law, with every clause linked to its source.
