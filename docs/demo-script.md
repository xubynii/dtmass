# Demo script — 3 to 5 minutes

Open the Pages link in a wide browser window before class so the fonts, the three.js library and the downtown model are already cached. The tool opens on the Site tab with the 1189 Howe St demo.

**0:00 — What it is for (30 s)**
"A massing tool for downtown Vancouver lots. You give it a program brief; it draws a tower massing you can edit, and every number it reports is checked against the Downtown ODP, the Building By-law and the Parking By-law, with the clause linked."

**0:30 — Site (30 s)**
Site tab: point at the parcel on the map, the lot area, zoning and the two restrictions that still need verification (ODP density and height areas are guesses from City data until confirmed). Say that the setback lines in the model come from the Downtown South Guidelines and are hard limits for blocks.

**1:00 — Brief and generate (60 s)**
Design tab → Development target: type a target floor area (for example 24000) and watch the massing regenerate. Program mix: drag Residential down and Hotel up; the total band goes amber, press Normalize to 100%, the massing follows. Massing typology: click Split Towers on a Shared Podium, then back to Podium + Tower. Point at the requested-versus-generated table and the conflict line: the brief exceeds the FSR and the height for this lot, and the panel says by how much and what would resolve it.

**2:00 — Edit (60 s)**
In 3D, click the tower, pull its roof face up two storeys, pull a side face toward the lane and show that it stops at the setback line. Open Shape the building, pick Tapered shaft, add Cascading spiral terraces. In the right panel, show the block's storey range and its share of the program against the target. Shift-click the retail podium for the fire separation (Group C to Group E, 2 h, Table 3.1.3.1).

**3:00 — Check and report (45 s)**
Check tab: open one failing item, read Current, Requirement and the clause link; click the link to show it lands on the by-law section. Report tab: the first page is the project data sheet; scroll to the clause links in the appendix.

**3:45 — Compare (30 s)**
Save version, change the typology, save again; Compare shows matched axonometrics, program shares against the brief and what improved or got worse.

**Close (15 s)**
"It is a screening tool: a pass here is not a permit. The README lists every source with its date and what the tool does not check."

If something fails live: Undo (Ctrl+Z) restores the previous state; reloading the page returns to the demo.
